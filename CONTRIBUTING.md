# Contributing

This repository is a frozen research release. Bug reports and reproducibility issues are welcome. Please include:

- operating system and Python version;
- installation method;
- exact command;
- configuration file and environment variables with local paths redacted;
- full traceback;
- whether the issue occurs on synthetic smoke tests or only on third-party data.

Do not upload or attach restricted Waymo/CommonRoad raw data to an issue.
