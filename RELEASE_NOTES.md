# Release notes — v1.1.0

This is the public code release corresponding to the v1.1 manuscript evidence chain.

## Included

- Waymo actionability endpoint and confirmatory OOF analyses;
- CommonRoad outcome-blind 10k cohort and fixed planner taxonomy;
- strict tied-threshold fixed-FPR evaluation;
- CommonRoad-CriMe-style, RSS-style, drivability and forecast-risk baselines;
- 35-candidate lattice-base and 130-candidate lattice-extended sensitivity;
- non-action, temporal and label-feature mismatch decoupling audits;
- low-speed collision-heavy boundary analysis;
- final plotting scripts for manuscript Figures 2–5 and Supplementary Figures S1–S9;
- synthetic tests and public-release checks.

## Excluded

- raw Waymo/CommonRoad data;
- generated work directories and result tables;
- the separately deposited evidence-lock archive;
- old backup files, IDE metadata, manuscript-editing scripts and superseded pilot plotting code.
