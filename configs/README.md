# Configuration files

All public configurations are path-portable and expand these variables:

- `${ROF_WORK_DIR}`
- `${WAYMO_SCENARIO_ROOT}`
- `${COMMONROAD_SCENARIO_ROOT}`

Create an ignored local copy of `actionability_main_example.yaml` for exploratory work. The versioned `nc_v*` YAML files are the frozen paper configurations and should not be edited when reproducing the locked analyses.
